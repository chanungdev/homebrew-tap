# Chanungdev Tap

## How do I install these formulae?

`brew install chanungdev/tap/<formula>`

Or `brew tap chanungdev/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "chanungdev/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
